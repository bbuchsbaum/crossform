# Agent entry point

Read `design/agent-system-contract.md` for the shared scientific-state design,
then `design/pattern-model-interop-plan.md` for the smallest eligible next change.
The protocol is proposed; documentation is not evidence that a new API exists.

Resolve the checked-out commit before using a branch name or an old receipt.
This revision is based on `elite-pass` at `b7cffa9`; it does not move `main`.
Use current exports/help/source for callable APIs. `fit_geometry()` and
`score_geometry()` learn/score geometry, not class labels or voxel loadings.

Contracts own mathematical meanings; `design/evidence-status-ledger.md` and its
existing CSV registry own scientific claim status. Keep independent evidence,
fitted PSD forms and descriptive projections distinct. Preserve source ancestry,
held-out outcome exposure, units, frame normalization and metric composition.

Do not forge private fit classes, assume learned measurements are fixed, make a
dense whole-brain covariance, or bypass population/uncertainty refusals.
Use optional package adapters rather than an rMVPA dependency in crossform.

For a documentation task, validate links, JSON examples, source references and
scope. For code, run owning tests, independent oracles and the existing
certification-binding procedure in `benchmarks/RECERTIFY.md` as applicable.
An old green receipt is not a new test run. Do not claim R tests or CI passed
without observing their exact outputs and source identity.

Do not install into the user's library or rewrite benchmark criteria to pass.
End a handoff with commit, changed files, checked gates, unrun gates, unresolved
refusals and the cheapest valid next action. No unbounded chat-history dump.
