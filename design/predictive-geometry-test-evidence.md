# Predictive geometry requirement evidence

G22 audit, 2026-09-05. This is a requirement map, not a count of test tags.
The final integrated run and source-bound receipt are recorded in
[predictive-geometry-certification.md](predictive-geometry-certification.md).
The final integrated gate is complete; all T01–T62 statuses in the implementation
JSON are complete with their concrete evidence pointers. The separate incoming
CRAN note is explained in the certification report.

The mathematical oracle is `design/oracles/predictive-geometry.R`. It supplies
independent analytic fixtures; the production mutation run separately proves
that the actual implementation is exercised and scientifically wrong variants
are detected. Tests compare invariant forms and declared targets rather than
incidental eigenvector signs or latent rotations.

The audit added public integration witnesses for T06/T08/T10/T23/T55. Test tags
in early kernel tests alone did not establish those complete public-path laws.
T55 uses the existing typed input boundary for raw spectrum/covariance calls;
new-condition and unsupported loss/metric paths carry capability reason codes.
No fitted-eigenvalue inference or learned-metric score is claimed.
